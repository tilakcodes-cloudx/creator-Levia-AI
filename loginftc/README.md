# Cosmic Night - Modern Sign In / Auth UI

A pixel-perfect, responsive implementation of the dark cosmic starry night login interface.

## ✨ Features

- **Pixel-Accurate Visuals**: Replicates the template's deep cosmic starry night aesthetic, subtle nebula glow, typography, and dark translucent glassmorphism form.
- **Dynamic Starfield Canvas**:
  - Twinkling stars with sine-wave luminescence and celestial color warmth.
  - Interactive mouse parallax depth layers.
  - Shooting star streak at the title matching the template reference + animated passing meteors.
- **Form Controls & Micro-Interactions**:
  - Custom pill-style inputs (`border-radius: 16px`) with soft glass translucent background.
  - Password visibility toggle (interactive eye SVG icon).
  - Custom rounded checkbox ("Remember me").
  - "Forget Password ?" trigger with validation flow.
  - Primary "Sign In" button with loading spinner state and tactile press effect.
  - "Don't Have an Account ? Sign Up" mode switcher.
  - 5 Social Login Providers (Google, GitHub, Facebook, Microsoft/Windows, Passkey/Security Key) with hover glow and feedback toasts.
- **Responsive & Accessible**:
  - Mobile-first, works across all viewports (phones, tablets, laptops, ultra-wide screens).
  - High-contrast typography and semantic HTML tags.

## 🚀 How to Run

Simply open `index.html` in your favorite web browser (double-click the file or right-click -> Open with Chrome / Edge / Firefox).

Or run a local static server if preferred:
```bash
npx serve .
# or
python -m http.server 3000
```

## 📁 File Structure

- `index.html`: Semantic HTML5 markup, SVG icons, and accessible form structure.
- `style.css`: Clean CSS variables, typography, glassmorphism, responsive breakpoints, and animations.
- `script.js`: Dynamic 60fps starfield canvas, parallax, password toggle, form validation, and toast feedback.
